LAB VERIFICATION

IoT Practical Sessions (Tasks 1 – 5)

Comprehensive hands-on implementation completed during the IoT and Embedded Systems laboratory modules at KCT Forge.

TASK 01

NodeMCU (ESP8266) Firmware Setup & Basic Telemetry

ESP8266 • Arduino IDE • GPIO Pinout

Established the foundational development environment for the ESP8266 SoC. Configured CP2102/CH340 USB-to-UART bridge drivers, compiled embedded C++ payloads, and verified bidirectional serial communication at 115200 baud. Built GPIO pulse telemetry to confirm pin logic states and onboard LED health.

pinMode(LED_BUILTIN, OUTPUT); digitalWrite(LED_BUILTIN, LOW); // Active Low telemetry blink
TASK 02

Environmental Sensing & DHT Calibration

DHT11 / DHT22 • Digital Pulse Signaling

Interfaced digital humidity and temperature sensors via single-wire bus architecture. Implemented checksum validation over 40-bit transmission packets to filter electrical noise spikes. Calibrated real-world room ambient data with continuous rolling average smoothing.

float h = dht.readHumidity(); float t = dht.readTemperature(); // Checksum verified
TASK 03

Actuator Driving & Optocoupler Relay Isolation

5V Relays • Flyback Diodes • High Load Control

Addressed the low-voltage limitation of microcontroller logic (3.3V) by introducing optically isolated transistor driver arrays. Controlled 230V AC mock loads safely without inductive back-EMF feedback resetting the microcontroller logic core.

TASK 04

Wireless Bluetooth Serial Telemetry & Mobile Control

HC-05 / ESP32 Bluetooth • RFCOMM • Mobile App

Deployed a wireless RFCOMM serial channel enabling a paired mobile terminal to transmit byte-level control codes and receive real-time state telemetry. Configured automatic reconnection handshakes and buffer flush routines.

TASK 05

Cloud Telemetry Dashboard & ThingSpeak Integration

HTTP GET / POST • ThingSpeak REST API • Charts

Connected NodeMCU to local Wi-Fi (WPA2) and implemented periodic HTTP POST requests streaming multi-field sensor telemetry to the ThingSpeak Cloud IoT platform. Verified rate-limiting intervals (15-second minimum throttle) and generated real-time historical graphs for temperature and humidity.
